# Master It Skill

Transform codebase modules, subsystems, algorithms, and external software engineering concepts into deep, durable, senior-level interactive HTML lessons backed by grounded external research and line-by-line mechanics.

## Install

```bash
npx skills add dimsedra/skills --skill master-it
```

## Features

- **Senior Developer Lens & Systems Thinking**: Dissects concepts from the perspective of architecture, invariants, trade-offs, operational boundaries, and hidden failure modes.
- **Uncompromised Depth**: Prioritizes thorough, durable documentation over artificial brevity. Never truncates essential mechanics.
- **Annotated Code Highlights**: Every code snippet includes an explicit Input-Process-Output and line-by-line logic breakdown.
- **Hybrid Bridging for Codebases**: Connects internal repository code to foundational Computer Science principles (e.g. Actor Model, Token Buckets, LSM-Trees) to build transferable skills.
- **Grounded Research & External Citations**: Automatically researches and cites authoritative sources (RFCs, official docs, engineering blogs).
- **Standalone Interactive HTML Lesson**: Generates styled monochromatic deliverables using `report-in-html` with dark/light themes and background live server delivery.
- **Post-Delivery In-Chat Socratic Dialogue**: Offers optional 2–3 question scenario-based inquiry in chat to lock in mental models.

## Files Reference

- `SKILL.md`: Core invariants, execution phase gates, failure modes, and red flags.
- `LESSON-FORMAT.md`: Full HTML lesson schema, component taxonomy, and Socratic question guidelines.
- Dependency: Uses `report-in-html` for HTML generation and styling.
