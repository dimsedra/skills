# Research Skill

Conducts outward-facing technical research grounded in authoritative documentation, installed dependencies, and proven real-world codebases rather than static training data.

## Install

```bash
npx skills add dimsedra/skills --skill research
```

## Features

- **Outward Grounding**: Prioritizes authoritative docs, release notes, and real code over static or hallucinated training data.
- **Dependency Truth**: Inspects actual installed packages, type declarations, and interfaces in the local environment.
- **Battle-Tested Focus**: Biases toward robust, production-proven approaches instead of brittle experimental hacks.
- **Prior Art & OSS Reference**: Finds and inspects open-source projects solving similar problems to what is being built.
- **Confidence Over Haste**: Takes as much time and thorough investigation as needed to ensure reliable, high-confidence findings.
- **Direct & Unadorned Answers**: Answers what was asked directly without forcing artificial report templates or boilerplate fluff.
- **Universal & Stack-Agnostic**: Works seamlessly across any language, framework, or ecosystem.
