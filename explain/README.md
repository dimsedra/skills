# Explain Skill

Facilitate deep, peer-to-peer technical comprehension of concepts, modules, or codebases through collaborative discussion.

## Install

```bash
npx skills add dimsedra/skills --skill explain
```

## Features

- **Peer-to-Peer Engineering Posture**: Collaborative whiteboard-style discussion rather than a pedantic lecture.
- **Preference-Driven Alignment**: Automatically respects communication preferences from `AGENTS.md`, `GEMINI.md`, or `CLAUDE.md`.
- **User-Led Completion**: Concludes naturally whenever the user indicates they have understood.
- **Optional Report Hand-off**: Seamlessly links to `report-in-html` (with auto-installation) if a persistent visual report is desired.
